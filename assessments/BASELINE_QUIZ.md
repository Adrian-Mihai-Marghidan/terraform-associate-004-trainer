# Optional gentle baseline

Use after an introduction or when requested. This is not a full diagnostic exam, a prerequisite, or proof that later topics can be skipped.
The tutor asks one item at a time and reveals explanations after the learner responds.
This baseline is unscored. Objective IDs locate the concepts; answers and any help are introductory observations, not independent readiness evidence or permission to skip lessons.

1. **Objective 1a.** In your own words, what does "desired state" mean?
2. **Objective 2b.** Which component normally builds a Terraform execution plan: Terraform Core or a cloud provider?
3. **Objectives 3d, 3e.** True or false: an ordinary Terraform plan applies every listed change immediately.
4. **Objective 4c.** Choose one: what is an output intended to expose?

   - A. A useful value from a configuration
   - B. The provider download archive
   - C. The Terraform executable

5. **Objective 3a.** Choose two: which activities belong to an ordinary change workflow?

   - A. Reviewing the proposed changes
   - B. Applying the approved changes
   - C. Manually deleting all state before each run
   - D. Treating every plan as an already-completed deployment

Record assistance and explanations. Later fresh questions assess objective understanding; these introductory items are not calibrated to official difficulty.
