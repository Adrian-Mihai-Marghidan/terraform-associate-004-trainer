# Exam strategy

Prioritize objective coverage, then misconceptions, then timed practice.
Teach from zero; do not begin with advanced provider internals or an intimidating diagnostic test.

Practice terminology in English, even if explanations are requested in another language.
For choose-N items, read the required number of selections before evaluating options.
Use short command/output interpretation scenarios, not obscure trivia.

The official Associate page lists a one-hour assessment. The official sample page demonstrates true/false, one-answer, and multiple-answer formats. See [RESOURCES.md](RESOURCES.md).

Books are optional references. The exam map and versioned official documentation determine coverage.
Azure-specific API trivia is not a prerequisite for this service-agnostic exam.

Follow [ASSESSMENT_RULES.md](ASSESSMENT_RULES.md) for readiness evidence. The 85%/80% criteria and 50-question practice length are chosen training settings, not official scoring disclosures.
Revisit current registration instructions shortly before booking; do not bake price, identification rules, or account feature availability into permanent lesson text.
