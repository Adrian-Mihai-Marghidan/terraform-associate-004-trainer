# Gap tracking contract

Actual gaps live in `private/KNOWLEDGE_GAPS.md`.

Record: gap ID, objective, observed misconception, dated evidence, a targeted correction, a new independent retrieval task, and status.
A guessed weakness based on profession or a blank tracker is not an observed gap.
Close a gap only after a correct independent response and a delayed review.
Do not mistake a corrected agent-generated question for a learner misconception.
