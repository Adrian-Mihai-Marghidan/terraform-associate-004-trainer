# Assessment playbook

Read repository `docs/ASSESSMENT_RULES.md` before scoring or reporting readiness.

## Ordinary review

Use two to five original items after teaching.
Map each item to objective IDs and verify its rationale against an official source.
Use a new context for delayed review. Record hints and previous exposure.
After answers, explain the correct choice and each distractor.

## Timed practice

Prepare and verify the whole set and key before presenting questions.
Write the frozen version to `private/assessments/<attempt-id>/`.
Ask the learner to start a 60-minute timer and record the actual start time.
Present choose-one, choose-N, and true/false items with clear instructions.
Withhold solutions until submission. A learner request for teaching pauses exam mode and labels the attempt interrupted or assisted.

At scoring, retain the original answer key, compute the raw denominator after invalid items are excluded, and show results by objective and domain.
Exclude repeated/assisted items from unseen readiness scores.
Agent-built infrastructure and simulator acceptance checks contribute no learner assessment evidence. Simulator behavior is a limited resource contract; ground Terraform exam rationales in official HashiCorp documentation.
Do not copy leaked questions or certify that generated difficulty matches the official exam.
Do not turn an 85% practice result into an official passing threshold.

## Completion

Create targeted revision tasks from actual mistakes.
Update due reviews and progress only after recording the evidence.
Report practical execution separately, including any conceptual-only HCP study.
